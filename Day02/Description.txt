## 1. Core concepts.
- Concepts of Lists:
    - Definition and Syntax: How to store an ordered, mutable collection of items using square brackets [].
    - Indexing and Slicing: How to access specific elements using zero-based indices and extract sub-lists using ranges.
    - Mutation and Methods: How to modify lists dynamically by adding (append, insert), removing (remove, pop), and sorting elements.
    - Heterogeneity: How to store multiple data types (integers, strings, floats, or even other lists) within a single collection.
    - Iterability: How to traverse and process list elements efficiently using loops.
- Input: How to capture user data from the console using the input() function.
- Output: How to display results, variables, or messages to the screen using the print() function.

## 2. Simple Project: Mini Expense Tracker
- Project Objectives:
    - Master Python Lists: Learn to manipulate, search, sort, and organize data collections.
    - Apply Variables: Store and process aggregate metrics (totals, counts, averages).
    - Practical Application: Build a functional tool to manage financial records using standard Python methods.
- Functional Requirements:
    - Initialization & Input: Initialize a list with at least 3 values. Capture a new expense from the user and add it to the list using append().
    - Precise Insertion: Allow users to specify an index and a value to add an expense at a particular position using insert().
    - Merging Lists: Define a secondary list and combine it into the main expense list using extend().
    - Removal by Value: Prompt the user for an expense amount to delete and use remove() to clear the first occurrence of that value.
    - Removal by Index: Utilize pop() to remove the last item and display the value that was removed.
    - Searching & Counting: Use index() to locate a specific value's position and count() to identify frequency of a specific expense amount.
    - Sorting & Reversing: Organize the list in ascending order using sort(), then reverse the sequence using reverse().
    - Calculations & Output: Compute total (sum), count (len), and average using variables. Display the final list and insights clearly.
    - Reset: Include an option to clear the entire dataset using clear().
- Implementation Details:
    - Programming Language: Python 3.x
    - Key Methods: append(), insert(), extend(), remove(), pop(), clear(), index(), count(), sort(), reverse().
    - Data Management: Use variables to store calculation results and f-strings for formatted console output.
