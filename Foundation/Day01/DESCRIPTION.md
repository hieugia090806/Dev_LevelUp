# Project: Student Management System (SMS). #
> Purpose: The personal project build a console-based Student Management System using Python while learning and applying core programming concepts, including variables, conditions, loops, functions, data structures, file handling, and object-oriented programming.
## Phase I: Student Information Collection. ##
    - In Phase I, the system allows users to enter basic student information, including the student's name, age, and grade. The entered data will be stored in variables and displayed back to the user in a formatted output. This phase focuses on understanding the fundamental concepts of Python programming and establishing the foundation for future phases of the Student Management System.

    - Learning Objectives
        * Understand Python variables and data types.
        * Practice user input and output operations.
        * Apply type conversion for numeric data.
        * Store and display student information correctly.
        * Develop confidence in writing simple Python programs.
