## 2. Simple Project: Student Grade Management System
- Project Objectives:
    - Master Python Lists: Learn to manage, search, sort, reverse, and update student records.
    - Apply Variables: Store student information, grades, and user selections.
    - Practice Conditional Logic: Categorize student grades using if-elif-else statements.
    - Utilize Loops: Process multiple grades efficiently using iteration.
    - Practical Application: Build a simple academic management system using core Python concepts.
- Functional Requirements:
    - Student Registration: Allow users to enter at least three student names and store them using extend().
    - Grade Entry: Allow users to enter at least three grades and store them in a grade list.
    - Grade Categorization: Classify grades into categories A, B, C, D, and F according to predefined ranges.
    - Student Addition: Allow users to add a new student using append().
    - Student Removal: Allow users to delete a student using remove().
    - Student Search: Allow users to search for a specific student in the list.
    - Student Sorting: Sort student names alphabetically using sort().
    - Student Reversal: Reverse the order of student names using reverse().
    - Grade Analysis: Display the highest and lowest grades using max() and min().
    - User Navigation: Provide options for users to continue interacting with the system or exit the program.
- Implementation Details:
    - Programming Language: Python 3.x
    - Key Methods: append(), extend(), remove(), sort(), reverse(), max(), min().
    - Control Structures: if, elif, else, and for loops.
    - Data Management: Use variables and lists to store and process student information.
    - Output Formatting: Use f-strings for clear and readable console output.
