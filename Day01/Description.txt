## 1. Core Concepts
- Concepts of Variables: How to store and label data in memory using variable names.
- Basic Data Types: 
    - float (floating-point numbers - used for decimal precision), 
    - int (integers for whole numbers), 
    - string (text characters).
- Input/Output: Using the input() function to capture user data and the print() function to output results.
- Type Casting: Converting user input (which is captured as a string by default) into numerical types (float/int) to enable arithmetic operations.
